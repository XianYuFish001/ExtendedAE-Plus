# 优先级覆写卡
简单的优先级设置工具

## 使用方法
- **[右键]** 打开 GUI
- 在 GUI 中输入一个优先级值并选择一个工作模式
- 使用于拥有优先级的机器则可以将自身的优先级值复制到对应机器
