# Assembler Matrix Advanced Core
These cores are upgraded versions of the standard cores.

## Advanced Craft Core
<BlockImage id="extendedae_plus:assembler_matrix_advanced_crafter" scale="5" />
The Advanced Craft Core offers higher parallelism, with a maximum* of 128 threads per core, equivalent to 16 times the capability of a standard Craft Core.

_*See Advanced Speed Core._

---
## Advanced Pattern Core
<BlockImage id="extendedae_plus:assembler_matrix_advanced_pattern" scale="5" />
The Advanced Pattern Core has four times the pattern storage capacity of a standard core.

---
## Advanced Speed Core
<BlockImage id="extendedae_plus:assembler_matrix_advanced_speed" scale="5" />
The Advanced Speed Core provides three times the speed bonus* of a standard Speed Core.

_*With the standard core's speed bonus defined as 1, the Assembler Matrix reaches its maximum operating speed when the total speed bonus reaches 5. The Advanced Speed Core allows the speed bonus to continue accumulating beyond this limit._

> For every 5 points of speed bonus, the thread count of Advanced Craft Cores increases by 32.
